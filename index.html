[PILLAR 01]

FORMAL REACHABILITY MATRICES & GRAPH THEORY

+

By formalizing agent communications as directed adjacency matrices, reachability can be solved as an algebraic fixed-point problem. If $(I - A)^{-1}_{ij} > 0$, an untrusted agent node $i$ holds a deterministic path to mutate sensitive tool node $j$. This eliminates blind spots inherent in single-prompt audits.

[PILLAR 02]

INDIRECT PROMPT INJECTION & DELIMITER COLLISION

+

Autonomous agents scraping external web data or databases are vulnerable to embedded indirect prompt injection attacks. AGENT-TRACE dynamically wraps external input streams in cryptographic delimiter boundaries, preventing instruction evasion at the semantic router layer.

[PILLAR 03]

CIRCULAR STATE DEADLOCK CASCADE PREVENTION

+

When multiple autonomous agents critique each other's outputs without monotonic convergence criteria, they trigger state oscillation loops that consume millions of API tokens and crash server memory. AGENT-TRACE injects circuit breakers and deterministic rollback states.

PROJECT ABSTRACT

As multi-agent autonomous architectures rapidly displace monolithic LLM applications, inter-agent vulnerabilities—specifically prompt injection cascades, tool privilege escalations, and cyclic state deadlocks—have emerged as catastrophic failure modes.

AGENT-TRACE introduces a formal verification engine that maps execution topologies into mathematical directed reachability graphs, actively red-teams agent boundaries, and autonomously synthesizes deterministic AST guardrails with 98.4% detection recall.

SLIDE 05 // CORE ALGORITHMS & MATHEMATICAL FORMULATION

TAINT PROPAGATION & STATE VERIFICATION

ALGORITHMIC RIGOR
EQUATION 1: TRANSITIVE REACHABILITY
R = (I - α · A)⁻¹
Where $I$ is the identity matrix, $A$ is the normalized agent transmission adjacency matrix, and $\alpha \in (0, 1)$ is the attenuation factor. Non-zero entries in $R_{ij}$ define reachable vulnerability paths.
EQUATION 2: ITERATIVE TAINT DYNAMICS
τ(t+1) = α · A · τ(t) + (1 - α) · e_k
Updates taint concentration $\tau$ at time step $t+1$, seeded by an untrusted payload at ingress node $k$. If $\tau_{\text{DB}} > \epsilon_{\text{threshold}}$, an automatic guardrail circuit-breaker triggers.
